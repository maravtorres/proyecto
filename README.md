# Proyecto de Análisis de Vehículos 

Esta aplicación web permite explorar un conjunto de datos de vehículos en Estados Unidos, facilitando el análisis interactivo mediante gráficos.

##Aplicación en línea
https://proyecto-mhzg.onrender.com

## Funcionalidades
- Visualización de histogramas
- Gráficos de dispersión
- Exploración interactiva de datos

## Tecnologías utilizadas
- Python
- Pandas
- Plotly Express
- Streamlit
